What it cannot see

  • The track. The same driver form is used at every circuit, so a street-circuit specialist gets no credit.
  • Weather, safety cars, strategy calls and first-lap crashes, which is why a quarter of the field's results still surprise it.
  • Anything that changes between qualifying and the race, such as penalties after the grid is set or a car change.
  • The 2026 car rules are new. Last year's team form is deliberately ignored, so the first races of the year rest on very little data.
  • The driver line-up for the next race is assumed to match the last one.

How it is built

  • Every prediction uses only races that happened earlier. Before each test race the model was refitted from scratch. A test confirms a race's features ignore its own result.
  • Settings were chosen on the 2023 season only. 2024 onward was used once as the final exam.
  • Finishing position is predicted as a percentage of the field. Retirements are modelled separately. The race is then simulated 4,000 times with realistic random error to get the odds.
  • The what-if on the Set the grid tab runs the same simulation in your browser. It was checked against the Python version and agrees to within 0.4 percentage points.
